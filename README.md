# 📊 E-Commerce Sales Analysis | SQL Case Study

## 📌 Project Overview
This project analyzes an e-commerce sales dataset using SQL to extract meaningful business insights. 
The analysis focuses on revenue trends, customer behavior, and product performance to support 
data-driven business decisions.

## 🧠 Problem Statement
The business wants to:
- Track overall revenue performance
- Identify monthly sales trends
- Find top-selling products
- Identify high-value and repeat customers

## 🎯 Key Performance Indicators (KPIs)
- Total Revenue
- Monthly Revenue Trend
- Top 5 Most Sold Product Categories
- Top 3 High-Value Customers
- Repeat Customer Count

## 🛠️ Tools & Technologies
- SQL (MySQL)
- Google Docs (Documentation)
- Power BI / Excel (Optional Visualization)
- GitHub

## 🗂️ Dataset Details
- Table Name: `orders_100`
- Columns:
  - order_id
  - customer_id
  - product_category
  - amount
  - order_date

## 📈 SQL Analysis Queries
- Total Revenue Calculation
- Month-wise Revenue Analysis
- Top-selling Product Categories
- High-value Customer Identification
- Repeat Customer Analysis

SQL queries are available in the `sql_case_study_ecommerce/` folder.

## 🔍 Key Insights
- A small group of customers contributes significantly to total revenue.
- Certain product categories outperform others in sales volume.
- Monthly trend analysis helps identify seasonal demand.
- Repeat customers indicate strong retention and brand loyalty.

Revenue trends and product performance dashboards can be created using Power BI or Excel.
